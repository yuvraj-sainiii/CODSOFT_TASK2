## About the Project

This project is developed as part of Task 2 of the CodSoft Java Development Internship. It calculates the total marks, average percentage, and grade of a student based on the marks entered for each subject.

## Features

* Takes the number of subjects as input.
* Accepts marks for each subject.
* Calculates total marks and average percentage.
* Assigns a grade based on the percentage.
* Checks whether the entered marks are valid.
* Displays the final result.

## Technologies Used

* Java
* Scanner class
* Loops and conditional statements

## Grading System

| Percentage | Grade |
| ---------- | ----- |
| 90–100%    | A+    |
| 80–89%     | A     |
| 70–79%     | B     |
| 60–69%     | C     |
| 50–59%     | D     |
| Below 50%  | F     |

## How to Run

1. Install JDK on your system.

2. Download or clone this repository.

3. Open the project folder in the terminal.

4. Compile the program:

   javac StudentGradeCalculator.java

5. Run the program:

   java StudentGradeCalculator

## Example

Suppose a student enters the following marks:

* Subject 1: 85
* Subject 2: 90
* Subject 3: 78
* Subject 4: 88
* Subject 5: 79

Output:

* Total Marks: 420/500
* Average Percentage: 84.00%
* Grade: A
* Result: Passed
